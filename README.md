# QuickStart Cybersecurity Career Simulations

Three structured penetration-testing exercises completed as part of the **QuickStart Cybersecurity Bootcamp** (UC Santa Barbara Extension), each documenting a full engagement end-to-end: environment design, enumeration, exploitation, findings, and proof of completion.

This repository documents **guided bootcamp coursework** — distinct from my self-directed [home-cybersecurity-lab](https://github.com/ChowHusky21/home-cybersecurity-lab), which I designed, built, and ran independently outside of any course. Both reflect real, hands-on penetration-testing skills — this repo shows how I execute a structured, scenario-driven engagement; the home-lab repo shows how I design and operate one from scratch.

## Simulations

| # | Title | Focus |
|---|---|---|
| 2 | [Security Operations](sim-2-security-operations/README.md) | Vulnerability enumeration & scoring, Metasploit exploitation, root access, persistence, password cracking, hardening recommendations |
| 1 | [Creating a Secure Network](sim-1-secure-network/README.md) | Tri-homed DMZ network design, troubleshooting, port-scanning baseline, plaintext-credential capture |
| 3 | [Capture the Flag](sim-3-capture-the-flag/README.md) | EternalBlue (CVE-2017-0144) exploitation of a Windows target, Meterpreter post-exploitation, flag capture |
