# Security Policy

## Scope

This repository documents completed exercises from the QuickStart Cybersecurity Bootcamp, performed only inside the bootcamp's own sanctioned, isolated training environments. It contains no original exploit code, no live credentials, and no data from any real-world system.

## Supported Versions

This is a documentation repository, not versioned software — there are no supported/unsupported release lines. The current `main` branch reflects the completed, final state of the coursework.

## Reporting a Concern

If you believe any content here could be mistaken for guidance to test a real, non-consenting system, or find an error in a write-up, please report it privately rather than through a public Issue: daniel.t.harris@gmail.com.
